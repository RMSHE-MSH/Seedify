# seedify 开发期测试清单

**用途**：开发维护资产——SKILL.md 改动后逐条实测的行为验收标准。运行时不必读取。
**注意**：本清单只描述"输入特征 → 通过标准"，不包含任何输出范例（正例反例一律不进技能上下文）。
**结构**：四列——T编号 | 输入特征 | 通过标准 | 归属模块。归属模块取值：M1 seed-express / M2 seed-clarify / M3 seed-gen / M4 seed-tools / M5 seed-assemble / M6 seed-analyze / M7 seed-check / 编排器 seedify / 命令 / 发布（可多归属，逗号分隔）。

| T编号 | 输入特征 | 通过标准 | 归属模块 |
|---|---|---|---|
| T1 | 只说了一句要做什么 | 提示词不得含角色/流程/示例/风格 | M3 seed-gen, M5 seed-assemble |
| T2 | 原文含一处具体细节 | 提示词必须保留该细节 | M1 seed-express |
| T3 | 原文中途改口两次 | 以最终说法为准（对照不输出） | M1 seed-express |
| T4 | 意图含糊 | 先提问，不臆造，问清后生成 | M2 seed-clarify, M3 seed-gen |
| T5 | 任意输入 | 只有提示词；无改动对照、无依据、无整理段、无总结 | 编排器 seedify, M5 seed-assemble, 命令 |
| T6 | 无验收无边界 | 先开放提问补全信息后写入；用户说"没有"则不写；不编造 | M2 seed-clarify, M3 seed-gen |
| T7 | 触发短语含转写错字 | 仍正确触发并归一；内置件中文触发与错字变体同测 | 编排器 seedify, 命令 |
| T8 | 正常输入 | 输出提示词后不自动开工 | 编排器 seedify, 命令 |
| T9 | 含同音错字 | 提示词中已纠正 | M1 seed-express |
| T10 | 任意输入 | 无长诊断、无报告 | 编排器 seedify, M5 seed-assemble |
| T11 | 任意输入 | 提示词每处都能对应原文依据 | M1 seed-express, M3 seed-gen, M5 seed-assemble |
| T12 | 只说了一句目标 | 提示词就是一句，不补边界与验收，不套格式 | M3 seed-gen |
| T13 | 多处信息缺失 | 允许多轮提问直至信息完整，不设次数上限 | M2 seed-clarify |
| T14 | 装配时某槽位无料（上游未产出对应内容） | 该槽位整段省略，不为凑齐而补写内容 | M5 seed-assemble |
| T15 | 生成工具推荐清单 | 对话版每条注明来源与把握度；交付版不含来源与把握度 | M4 seed-tools |
| T16 | 用户给出流程、触发流程体检 | 评估建议只说在对话内，不进交付提示词；用户流程本身保留 | 方案席（to-spec） |
| T17 | 触发头脑风暴、产出候选方向 | 候选只作对话内选项，不直接写入提示词；经用户挑选确认后方可进【背景与已确认结论】 | M2 seed-clarify, M5 seed-assemble |
| T18 | 调用单模块命令 | 产出只含该模块产物，不夹带其他模块的产物 | 编排器 seedify, 命令 |
| T19 | 走 `/seedify` 全链路 | 最终交付仍是纯提示词，无过程段落、无质检报告 | 编排器 seedify, 命令 |
| T20 | 装配产出含合法脚手架段 | 不得误报为越界；对脚手架越界（流程写成硬约束、未确认内容入段、元信息混入）仍逐项指出 | M7 seed-check |
| T21 | 【方向与偏好】槽有内容 | 槽内只装已确认的取向/偏好，不得出现步骤/方法/顺序 | M5 seed-assemble |
| T22 | 任意表达或现成提示词输入意图解读 | 每处解读可回指输入依据；歧义先问不臆断；不产出改写版 | M6 seed-analyze |
| T23 | 输出检查报告 | 总结分只量纲领纪律符合度；报告附「不预测实践效果」声明；分数不作目标或门槛 | M7 seed-check |
| T24 | 被检提示词详细、结构完整或含示例 | 不因详细/结构完整/示例而加分 | M7 seed-check |
| T25 | 链路内已跑意图理解 | 意图理解产物不进最终交付提示词 | M6 seed-analyze, M5 seed-assemble, 编排器 seedify |
| T26 | `/seedify` 交付完成 | 不自动跑质检；交付仍纯提示词，质检由点名触发 | 编排器 seedify, 命令 |
| T27 | 分别产出分析产物与检查产物 | 分析产物不含质量评价；检查产物不含意图解读或改写 | M6 seed-analyze, M7 seed-check |
| T28 | 交付物含构建方案/语境词典 | 交付代码块只有提示词；方案与词典留在对话 | 方案席/装配 |
| T29 | 内置件机制被改写 | 设计树/frontier/推荐答案/不访谈等机制点 grep 在位 | 追问席/方案席 |
| T30 | 走方案席链路未经批准即成文 | 方案批准前不写提示词；跳层/单模块直调豁免 | 编排器 |

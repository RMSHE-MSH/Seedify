# M2 改造设计：内置 grill/to-spec 两席（v1 草案 · 待批准）

> 2026-10-22 · 对话定稿素材成文 · **批准前不动工**（门规则）
> 定位前提：Seedify 是**针对提示词的 Harness Engineering**（用户 2026-10-22 定调）。

## 1. 意图与为什么

自研的追问/头脑风暴不够成熟。工程上以市场标准衡量：经市场验证的热门开源（mattpocock/skills，6 万订阅者生态、GitHub 热门）成熟度与好用度高于自研——**不造轮子，直接纳入体系**（用户裁定）。v1 反馈「产出过于精简、缺乏结构、不够完善」的缺环，正是「想清楚再动笔」的中间产物缺失；外部成熟件恰好长在这一环上。

调研依据：`docs/research/README-mattpocock-skills.md`（round4）、`README-superpowers.md`（round5，对照记录）。原拟同时引入 Superpowers brainstorming，**已划掉**：其提问段与 grilling 重复，成文段 mattpocock 自家已有专职选手 to-spec——一家包办比两家混搭更干净，买的是被验证过的主链前半（grill → to-spec）。

## 2. 目标 / 非目标 / 反目标

**做**：
- M2 `seed-clarify` 撤销编制，拆为两席：
  - **追问席**：内置 grill 全家——`grilling`（追问引擎）+ `grill-me`/`grill-with-docs`（人触发入口壳）+ `domain-modeling` 与 GLOSSARY/ADR 格式文件（文档半边换皮**语境词典**：提示词项目的语境与决策沉淀）；
  - **方案席**：内置 `to-spec` 换皮——「不再访谈、只综合已知」，把追问席的产出综合成**提示词构建方案**（构建/生成/优化/装配的蓝图）；
- **流程体检**：编制撤销、能力吸收——压力测试段归追问席（grill 对流程分支刨根问底，推荐答案即体检意见形态），沉淀段归方案席（收进方案的构建决策/范围外，T16 纪律随行）；
- 内置 = vendored 进 `seedify/skills/`，随插件与 cowork zip 分发；
- 新链路：`seed-express → seed-analyze → 追问席 → 方案席 →（批准门）→ seed-gen → seed-tools → seed-assemble`。

**不做**：
- 不动七项裁定、不动总纲 v4 原文；
- 不动 M1/M3/M4/M5/M6/M7 本体（仅接口衔接：M3/M5 将「方案」纳入输入源）；
- 不引入 Superpowers brainstorming；不搬其 HARD-GATE 机构（门=编排器一条规则）；
- 不做 L2 循环进化 / L3 经验沉淀。

**反目标（做成即失败）**：
- 设计文档/方案混进最终交付物（裁定#5 破防）；
- 方案写成提示词逐句文本（代行 M3/M5，「方案是造提示词的蓝图，不是提示词里的蓝图」）；
- 内置件核心机制走样（设计树/frontier 收敛/推荐答案/「不再访谈只综合」等被改坏）；
- 外置硬依赖（要另装 mattpocock 插件才能跑 = 失败；必须自足内置）。

## 3. 约束

- **七项裁定全生效**。兼容口径明确一条：grilling 的「每题附推荐答案、yes=采纳」**保留**——它是提案不是填空模板，且其底色正是「open questions you answer in your own words」（与裁定#2 同源）；裁定#3 的作用域说明：正反例不进**我们技能文件的正文**，内置件原文属既有技能内容，不属样例注入。
- **charter 入包**：每席 `references/charter.md` 逐字节副本 + 运行前先读（裁定#4）。
- **Cowork 自足**：内置件全随 zip 走，无「装没装」问题。
- **MIT 合规**：两上游均 MIT，内置改写合法；须带版权声明（建 `THIRD-PARTY-NOTICES.md`，搭「分发时补 license」待办同波）。
- 工程红线照旧：无本机绝对路径、YAML 严格解析、版本双处一致、T1–T27 回归（T16 归属改挂方案席）。

## 6. 风险与已知取舍

- **grill 提问节奏（frontier 批问）**进入中文语音场景的实际体验待真机验证（发布门禁同波补测）；
- 内置件原文以英文为主：运行时对中文用户的对话输出自然转中文（技能是给模型的指令），换皮范围含「面向用户的章节」可中文化——程度随真机反馈调；
- to-spec 换皮后其「不访谈」约束依赖上游 grill 问透——单模块直调 to-spec 时输入不足怎么办：按其原设计「综合已知」，缺料交回编排器调度追问席（接缝契约自然覆盖）。
